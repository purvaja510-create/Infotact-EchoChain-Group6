
# EchoChain: Circular Economy & Secondary Market Lifecycle Analytics

## Infotact Solutions Internship | Project 2

EchoChain is an advanced data analytics and engineering project focused on understanding the post-sale lifecycle of electronic products.

The project combines secondary-market data with internal manufacturing BOM and warranty data to identify resale value, component lifecycle patterns, refurbishment opportunities, and overall product circularity.

### Technology Stack

- **Scrapy** – Web scraping of secondary-market electronics listings
- **Databricks & Delta Lake** – Data lakehouse storage and processing
- **PySpark** – Data cleaning, SKU extraction, fuzzy matching, and analytics
- **Power BI** – Executive dashboards and lifecycle analysis

### Key Metric

**Circularity Score** – A key analytical metric used to evaluate the potential for products and components to remain within the economic lifecycle through resale, reuse, and refurbishment.

### Project Goal

Build an end-to-end data pipeline that transforms secondary-market and internal product data into actionable sustainability and business insights.
